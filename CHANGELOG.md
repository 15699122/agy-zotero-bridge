## v1.2.0 (2026-11-19)

### Added (MinerU `.md` + `.doc`/`.docx` Supporting Information Routing & Proxy Diagnostics)
- **Attachment-Aware Workspace Rules (`src/mcp/zotero-mcp.mjs`, `src/context/prompt-builder.mjs`)**: Updated `buildScopedZoteroRulesMarkdown()` so PDF attachments use `paper_read`, while MinerU `.md` primary papers (without a PDF), `.txt`, `.html`, and `.docx` Supporting Information use `read_attachment({ target: { contextItemId } })` directly (re-calling with higher `maxChars` when truncated at `50,000` chars). Permitted selective `view_file`/`read_file` inspection of MinerU figures when no PDF exists, while warning against `.doc` binary limitations and text-only `.docx` image omissions; preserved `attachmentTitle` and `contentSourceMode` in `extractPaperScopeManifest()` and inspected `attachmentPath`/`filePath` in `collectContextDirectoriesFromRuntime()`.
- **`read_attachment` & `paper_read` Diagnostics (`src/mcp/stdio-http-proxy.mjs`)**: Added `annotateReadAttachmentDiagnostics()` and `annotatePaperReadErrorHint()` inside `compactMcpToolCallResponse()` to scrub garbled Word 97–2003 `.doc` binary payloads (`unsupported_binary_doc`), flag empty/image-only `.docx` extractions (`empty_or_image_only_docx`), annotate non-empty `.docx` XML-only text extractions + `50,000`-char default truncation (`truncationHint`), and append `read_attachment` routing hints when `paper_read` reports `no PDF or text attachment was found`.
- **Tests (`test/unit.test.mjs`)**: Expanded suite to **66 / 66** passing tests (`36` unit + `3` bundle + `27` integration), adding unit coverage for MinerU `.md` + `.doc`/`.docx` routing rules, proxy diagnostics (`unsupported_binary_doc`, `empty_or_image_only_docx`, `bridgeNotice`, `truncationHint`, `paper_read` hints), and manifest `attachmentTitle`/`contentSourceMode` preservation.

### Added (Zero-Maintenance Automatic CLI Model & Effort Discovery + Google `agy 1.5.11` Support)
- **Zero-Hardcode Automatic CLI Model & `--help` Effort Discovery (`src/agy/cli-probe.mjs`, `src/config.mjs`)**: Added `parseEffortLevelsFromHelp()`, extensible JSON `models` metadata parsing (`command.data.models` / `data.models` / `models`, explicit `efforts` / `supportedEffortLevels` / `thinkingLevels` arrays, `supportsEffort: false`), and automatic non-effort / fixed model detection in `resolveAgyModelAndEffort()` so any future Google/Anthropic/fixed model or `--effort` tier works automatically without editing bridge code (keeping family prefixes only as an offline fallback).
- **Discovery-First Disk Cache Hydration & Stale-While-Revalidate (`src/agy/cli-probe.mjs`, `src/http/server.mjs`, `src/agy/process-runner.mjs`, `src/claude-sdk/cli-shim.mjs`)**: Added `CliProbe.hydrateDiskCache()`, `AGY_MODELS_REVALIDATE_MS` (`120000` / 2m default), abortable background SWR refreshes (`refreshInBackground()`, `cliProbe.close()` hooked into `app.close()` and `cli-shim.mjs` exit), and smart Managed Mode metadata refresh probes in `cli-shim.mjs` so server-side new models appear automatically even when `agy.exe` keeps the same version.
- **New Google Models (`src/agy/cli-probe.mjs`, `test/fixtures/ndjson-samples.mjs`)**: Added offline fallback support and test fixtures for **`Gemini 4 Neon`** (`gemini-4-neon`), **`Orchestrator (Neon)`** (`gemini-pro-orchestrator-neon`), **`Gemini 4 Carbon`** (`gemini-4-carbon`), and any future `gemini-pro-orchestrator-*` orchestrator IDs.
- **Version-Aware `models-cache.json` Invalidation & Configurable TTL (`src/config.mjs`, `src/agy/cli-probe.mjs`)**: Added `isDiskModelCacheValid()` and `AGY_MODELS_CACHE_TTL_MS` (default `15m`) persisting `bridgeVersion`, `agyVersion`, and `effortLevels`, auto-invalidating whenever `agy.exe` or the bridge updates (while retaining `stale-disk-cache` fallback if live probing fails).
- **Tests (`test/unit.test.mjs`, `test/bridge.test.mjs`, `test/bundle.test.mjs`, `test/mock-agy.mjs`)**: Expanded suite to **65 / 65** passing tests (`35` unit + `3` bundle + `27` integration), adding `--help` parsing, zero-hardcode future model/tier discovery, `hydrateDiskCache` + SWR + `close()` abort verification, real `agy.exe 1.5.11` 23-variant -> 9-base-model parsing, `isDiskModelCacheValid`, and HTTP end-to-end dynamic discovery integration coverage.

## v1.1.0 (2026-11-19)

### Added (`M7-01`: Persistent Process Pool Defaultization & TTFT Tuning)
- **Retention-Aware Default Process Pool & Turn/Age Rotation (`src/config.mjs`, `src/agy/process-pool.mjs`, `src/agy/process-runner.mjs`, `src/agy/cli-probe.mjs`, `bridge.mjs`)**: Enabled `processPoolEnabled` by default (`AGY_PROCESS_POOL=0` disables, `AGY_PROCESS_POOL=1` forces pooling even for unmounted one-off HTTP turns) alongside `AGY_POOL_MAX_TURNS` (default `20`) and `AGY_POOL_MAX_AGE_MS` (default `25m`). Mounted Zotero chat tabs (`/runtime-retention` `retain: true`) automatically reuse warm `--input-format stream-json` `agy` children across turns, scale `--print-timeout` past `poolMaxProcessAgeMs`, preserve retention across automatic turn/age rotation (`keepRetained: true`), expose `processPool` status in `GET /healthz`, and terminate pooled children via `app.close()` on bridge shutdown.
- **Warm Child Reuse in Direct `Claude Code path` Shim (`src/claude-sdk/cli-shim.mjs`)**: Added warm `--input-format stream-json` process reuse (`warmRuntime`, `isWarmRuntimeReusable`, `spawnWarmRuntime`, `closeWarmRuntime`) with configuration signature isolation, `normalizeCumulativeUsage` delta computation, `maxTurnsPerProcess`/`maxProcessAgeMs` rotation, pre-tool 429 backoff retries, and clean teardown on `interrupt`, `plan` mode, `--json-schema`, `--no-session-persistence`, or `stdin` EOF.

### Added (`M7-02`: Local Semantic Vector Search Bridge)
- **OpenAI-Compatible Semantic Embeddings API (`src/embedding/embedding-service.mjs`, `src/http/server.mjs`, `src/agy/cli-probe.mjs`, `src/config.mjs`)**: Added `EmbeddingService`, `computeLocalSemanticEmbedding`, `cosineSimilarity`, and HTTP routes `POST /v1/embeddings`, `POST /embeddings`, and `GET /v1/embeddings/status`, advertising `'embeddings_v1'` in `/healthz`. Supports zero-key offline multilingual (EN + CJK) local semantic feature-hashing (`agy-local-ngram-v1`) as well as proxying external OpenAI/Gemini/Ollama backends (`AGY_EMBEDDING_API_BASE`) with chunked batching (`AGY_EMBEDDING_BATCH_SIZE`), persistent SHA-256 LRU disk caching (`AGY_EMBEDDING_CACHE_FILE`), and automatic 429 retry backoff. Compatible directly with `llm-for-zotero`'s **Custom** Semantic Search configuration (`http://127.0.0.1:8765/v1`).

### Added (`M5-01` & `M5-02`: Multimodal Figures & Batch Literature Optimization)
- **Multimodal Image & Figure Inspection (`src/context/prompt-builder.mjs`, `src/claude-sdk/cli-shim.mjs`, `src/mcp/zotero-mcp.mjs`)**: Added `parseImageDataUrl`, `validateImageBuffer` (PNG/JPEG/GIF/WEBP magic bytes & 20 MB cap), `materializeTurnImages`, `renderMultimodalImagePrompt`, and `extractSdkUserImageBlocks`. Base64 screenshots and `@anthropic-ai/claude-agent-sdk` `image`/`image_url` blocks are materialized into `<cwd>/.agents/multimodal-inputs/`, image attachments & Zotero `llm-for-zotero-pdf-figure-crops` directories are automatically discovered, and ephemeral `session-settings.json` grants both `read_file(<dir>)` and `view_file(<dir>)` rules alongside workspace instructions for `paper_read` `figures`/`visual`/`capture` workflows.
- **Batch Literature Review & Ultra-Long Context Compaction (`src/context/prompt-builder.mjs`, `src/mcp/zotero-mcp.mjs`)**: Added `extractPaperScopeManifest` (no 8-paper cap), `compactRuntimeContext` (progressive compaction guaranteeing valid JSON while preserving all paper metadata, collections, tags, and active notes), `renderBatchScopeGuidance` (3-tier `library_retrieve`/`paper_digest` -> batched `paper_read` `targets`/`outline`->`targeted` -> `review_coverage`), and `assembleTailSafePrompt` so `User request:` and attachment policies are never truncated.
- **Transient 429 Rate-Limit Backoff & Actionable Diagnostics (`src/config.mjs`, `src/agy/process-runner.mjs`, `src/claude-sdk/cli-shim.mjs`, `src/protocol/event-mapper.mjs`)**: Added `AGY_RATE_LIMIT_MAX_RETRIES` (default `1`) and `AGY_RATE_LIMIT_RETRY_DELAY_MS` (default `1500`) for automatic backoff retries before any tool side effects occur, plus `readDirs`/`mcpSettingsFile` tracking inside M4 `poolSignature`.
- **Research Documentation (`M6-02`, `M7-01`, `M7-02`)**: Updated `AGY_BRIDGE_DEVELOPMENT_PLAN.md` (Section 9) and `docs/UPSTREAM_CONTRACT.md` with source-verified findings and implementations for customizable Zotero/Obsidian note & tag templates (`M6-02`), default retention-aware hot runtime pooling (`M7-01`), and OpenAI-compatible local Semantic Search `/v1/embeddings` bridging (`M7-02`).
- **Expanded Tests (`test/unit.test.mjs`, `test/bridge.test.mjs`, `test/bundle.test.mjs`)**: **58 / 58** passing tests (`29` unit + `3` bundle + `26` HTTP/shim integration), verifying `M7-01` default retention PID reuse + `retain: false` release + `AGY_PROCESS_POOL=0` opt-out + `AGY_POOL_MAX_TURNS` rotation alongside `M5-01`, `M5-02`, and `M7-02`.

## v0.2.0 (2026-11-17)

### Added
- **Modular Architecture (`src/`)**: Split `bridge.mjs` cleanly into focused ESM modules (`src/config.mjs`, `src/http/server.mjs`, `src/agy/cli-probe.mjs`, `src/agy/process-runner.mjs`, `src/protocol/event-mapper.mjs`, `src/session/session-store.mjs`, `src/context/prompt-builder.mjs`, `src/mcp/zotero-mcp.mjs`, `src/security/redact.mjs`) while preserving `node bridge.mjs` entrypoint and HTTP backwards compatibility.
- **`POST /structured-completion`**: Stateless headless completion endpoint with `--json-schema` support, `timeoutMs` clamping, client abort cleanup, markdown JSON fence stripping, and strict JSON validation (never touches session storage).
- **Real `agy 1.5.9` Model & Effort Discovery**: `parseModelsStdout` now strips leading `"Fetching available models..."` status lines emitted by `agy.exe 1.5.9`; `GET /efforts` supports per-model capability queries (`?model=<id>`) with conservative `['default']` fallback for unknown models.
- **Separated Health Diagnostics (`GET /healthz`)**: Distinguishes `bridgeAlive`, `agyInstalled`, `agyAvailable`, and `agyAuthenticated: null` (`authStatus: 'unverified'`) rather than inferring authentication from `--version`.
- **Error Classification & Secret Redaction**: Structured classification (`rate_limited`, `auth_failed`, `model_not_supported`, `permission_denied`, `missing_result`, `timeout`, `cancelled`, `process_exit_error`) and automatic scrubbing of Bearer tokens, API keys, bridge tokens, credential filenames, and user home paths.
- **Windows Process Tree Cleanup & Atomic Persistence**: Uses `taskkill /PID ... /T /F` alongside `child.kill()` on Windows and retryable atomic temp-file renames for `sessions.json`.
- **M2/M3 Safe Foundations (Aligned with `llm-for-zotero v3.9.18`)**:
  - `src/mcp/zotero-mcp.mjs` & `src/mcp/stdio-http-proxy.mjs`: Supports `initialize` -> `notifications/initialized` -> `tools/list`, clear `HTTP 401` diagnostics, dynamic per-turn capture of Zotero `body.mcpServers` Bearer/Scope headers into workspace-local `<scopedCwd>/.agents/plugins/llm-for-zotero/` (without writing tokens into `mcp_config.json` or `~/.gemini/config/mcp_config.json`), and exact classification of all 47 `agy 1.5.9` tools + `llm-for-zotero v3.9.18` MCP tools.
  - `src/agy/cli-probe.mjs`: Emits `supportsEffort`, `supportedEffortLevels` (upstream `modelCatalog.ts` shape), and advertises `local_pdf_paths` in `/healthz`.
  - `src/context/prompt-builder.mjs`, `src/agy/process-runner.mjs`, & `src/security/redact.mjs`: Upstream `runtimeRequest.localDocuments` (`%PDF-` signature validation, `--add-dir`, ephemeral non-resumed turn, streaming `[local-pdf-path:...]` redaction), untrusted `<zotero_reference_context>` wrapping, first-turn-only skill loading (`AGY_SKILLS_DIR`), and strict `validateLocalFilePath` checks.
